# 시즌·규정·밸런스 자동 반영

앱(백엔드)이 켜져 있는 동안 두 가지를 스스로 확인한다. 사람이 버튼을 누를 필요가 없다.

| 무엇 | 출처 | 주기 | 코드 |
|---|---|---|---|
| 랭킹·채용률 | Champions Battle Data (`/api/rankings?limit=1` 로 버전만 먼저 확인) | 시작할 때, 그 뒤 6시간마다. 공식 시즌·레귤레이션이 바뀌면 바로 한 번 더 | `collector.collect`, `main._refresh_data` |
| 시즌·레귤레이션·밸런스·점검 공지 | champions-news.pokemon-home.com (`/ko/json/list.json` + 한국어·영어 본문) | 10분마다 | `official_news.refresh` |

## 공지 → 규칙

`live_rules.compile_rules(dataset, notices, now)` 가 매 분 다시 계산한다. 결과(규칙 버전)가 바뀌면 엔진을 새로 만들고,
진행 중인 가상 배틀은 시작할 때의 엔진으로 끝까지 간다. 병렬 모의전 작업자도 같은 규칙을 받는다.

- **레귤레이션**: 기간 안이면 메가진화 횟수, 참가 목록(공식 web-view 목록), 새 메가진화를 적용한다.
  세부 규정이 아직 없으면(예고 공지) 이전 규정 + 새로 발표된 포켓몬을 모두 허용한다.
- **밸런스 조정**: 영어 본문에서 기술 수치(명중·위력·우선도·풀죽음 확률), 새로 배우는 기술, 특성 변경을 읽는다.
  적용 시각 순서: 공지의 시각 → 점검 종료 공지(실제 > 예정) → 같은 날 시작하는 공식 시즌·레귤레이션 시각(추정)
  → 그날 자정(한국 시간). 지금까지 업데이트 점검은 새 시즌 시작 시각에 열렸다 (11월 4일 02:00~04:00 UTC).
- **새 포켓몬**: 랭킹 원본에 아직 없으면 공개 도감(Showdown pokedex·learnsets, 9세대 습득 기술)으로 임시 항목을 만든다
  (`provisional.py`). 능력치는 레벨 50 실수치(HP 종족값+75, 나머지 +20). 원본에 들어오면 원본 데이터가 이긴다.
  도감 파일은 공지 확인 스레드가 미리 받는다 (엔진 잠금 안에서 내려받지 않는다).
- **시즌 번호**: 새 시즌 공지는 시즌이 시작된 뒤에 올라오므로, 그 사이에는 직전 시즌 다음 번호로 추정해 '(추정)'으로 표시한다.

## 알림

- `ruleAlerts` (설정 배지): 앱이 자동으로 처리할 수 없는 것만. 예: 공식 참가 목록을 도감과 맞추지 못함, 새 포켓몬을
  어디에서도 찾지 못함, 해석하지 못한 밸런스 문장, 모의전에 없는 새 기술 효과, 바뀐 시간 제한·도구 규칙.
- `ruleNotes` (배지 없음, 설정 '시즌·규정 자동 반영'): 자동으로 처리한 것. 예: 밸런스 적용 예정/적용됨, 임시 데이터 사용,
  세부 규정 대기.

## 한계

- 밸런스 문장 중 정해진 형식(`A% → B% accuracy` 등) 밖의 것은 자동으로 못 읽고 알림으로 남긴다.
- 모의전에 없는 효과를 가진 새 기술은 습득 목록에는 들어가지만, 모의전 동작은 코드 수정이 필요하다 (알림으로 표시).
  12월 2일 조정의 자기암시·원더룸은 이번에 모의전에 구현했다.
- 임시 데이터의 습득 기술은 9세대 기준이라 챔피언스와 다를 수 있다. 채용률·랭킹은 원본에 등록되기 전까지 없다.

## 다음 시즌 미리보기 (시즌 시작 전 대비)

공식 공지로 다음 레귤레이션·밸런스 조정이 발표되면, 시작하기 전부터 그 규칙으로 계산해 볼 수 있다.

- `live_rules.upcoming(notices, now)`: 45일 안에 시작하는 발표된 변경 [(시각, 종류, 공지, 추정 여부)].
- `main.preview_engine()`: 그 변경이 모두 적용된 시각의 규칙으로 만든 엔진 (지금 규칙과 같으면 없음).
  팀 자동 구성·데미지 계산·스피드 티어 요청에 `preview: true` 를 주면 이 엔진을 쓴다.
- `POST /api/next-season` (`season_preview.py`): 바뀌는 것(공지 요약), 밸런스가 닿는 메타 상위 포켓몬(바뀐 기술 채용률,
  새로 배우는 기술, 바뀐 특성), 새 포켓몬의 메타 상위 30마리 상대 상성(잘 잡는 상대·위협), 내 팀 영향(바뀌는 멤버,
  새 포켓몬에 대한 대응 여부).
- 앞으로 시작할 레귤레이션에서 처음 발표된 포켓몬·메가는 시작 전까지 지금 규칙에서는 참가 불가로 막는다
  (`blocked`, `blockedMegas`).
- 팀 자동 구성 후보에 참가 가능한 임시 데이터 포켓몬을 넣는다. 상대 메타는 지금 통계 기준이라, 새 포켓몬은 상대로는
  아직 나오지 않는다 (화면에 안내).

앱: 메뉴 '메타 분석 → 다음 시즌', 그리고 팀 자동 구성·배틀 계산기의 '다음 시즌 규칙' 토글 (발표된 변경이 있을 때만 보인다).

## 새 앱 버전 알림

`GET /api/app/latest` 가 GitHub 배포 목록(공개 저장소)의 최신 버전을 6시간마다 확인한다. 앱 버전보다 새로우면
업데이트 버튼에 배지가 뜨고, 업데이트 내역 창 맨 위에 다운로드 페이지 링크가 보인다.
목표: 공지 해석·데이터·규칙·새 포켓몬은 자동으로 따라가고, 앱 배포는 시즌마다 한 번(모의전에 없는 새 효과 구현 등)이면 되게.
