이 앱만의 강점: 순위가 낮아도 메타를 넓게 잡는 조커 탐색, 팀 단위 전략 가이드, 상대 6마리 기반 선출 추천,
가상 배틀 반복 시뮬레이션. 약점이던 스피드 비교·팀 가져오기·배틀 화면 완성도는 이번에 보강했다.

## 1단계 — 설정과 다국어 기반 (완료)

- 설정 화면: 언어, 이름 표시 방식, 테마(시스템/어둡게/밝게), 글자 크기, 애니메이션 줄이기, 경기장 배경,
  기본 배틀 형식, 서버 주소와 연결 확인, 데이터 갱신, 로컬 데이터 초기화, 앱 정보·출처 표기.
- 언어: 한국어 / English / 日本語.
  - 앱 화면 문구는 앱이 그리는 시점에 번역한다 (`app/lib/i18n.dart`, 사전은 `app/lib/l10n_data.dart`).
  - 포켓몬·기술·도구·특성·성격 이름은 서버가 요청 언어(`X-Lang`)에 맞춰 바꿔 보낸다.
  - 한계: 서버가 문장으로 만들어 보내는 설명(전략 가이드, 운용법, 상대 전략 팁 등)은 아직 한국어다 → 5단계.

## 2단계 — 정밀 데미지 계산기

- 엔진 `damage()`에 필드 조건을 받는 인자를 추가: 날씨, 필드, 리플렉터/빛의장막/오로라베일, 도우미,
  랭크(-6~+6), 급소, 화상, 전체기 여부, 상대 수.
- 결과는 16단계 난수 전체(85~100%)로 계산해 확정/난수 n타 확률까지 표시.
- 새 화면 `/calc`: 공격 측·방어 측 세트(팀·검색·대표 세트에서 불러오기), 필드 조건 토글, 기술별 결과.
- 포켓몬 연구실의 대결 창과 상대 분석의 첫 턴 플랜이 같은 계산기를 쓰도록 연결.

## 3단계 — 턴 1 어시스턴트

- 입력: 현재 필드의 내 2마리·상대 2마리(더블), 남은 후발, 날씨/필드/순풍/트릭룸 남은 턴.
- 출력: 추천 행동 조합 2~3개와 근거, 상대의 예상 행동 분포(가상 배틀 CPU 정책 재사용), 실패 시 손해.
- 상대 분석의 "첫 턴 플랜"에서 바로 넘어갈 수 있게 한다.

## 4단계 — 데이터 자동 갱신과 추세

- 백엔드가 6시간마다 새 `dataVersion`을 확인해 수집(앱을 켜 둔 동안만, 설정에서 끌 수 있게).
- 쌓인 순위 스냅샷으로 7일/14일 순위 변동을 메타 화면과 포켓몬 상세에 표시.
- 원본 API 규칙(과도한 요청 금지, 캐시 허용)을 지키도록 요청 간격 제한.

## 5단계 — 서버 문장 다국어화

- `guide.py`, `lab.py`, `enemy.py`, `simulation.py` 등이 만드는 문장을 템플릿 키 + 인자로 바꿔 보내고,
  번역은 앱 사전에서 처리한다 (이름도 각 언어로).
- 남은 한국어 문장 수를 세는 테스트를 추가해 누락을 막는다.

## 6단계 — 배포와 품질

- Windows 설치 파일, Android APK 빌드 절차 정리 (서버 주소는 설정에서 입력).
- 백엔드 단위 테스트 확대, Flutter 위젯 테스트(설정·언어 전환), GitHub Actions에서 테스트 실행.

## 보류 / 아이디어

- LLM 설명 레이어: 분석 결과(JSON)를 사람이 읽기 쉬운 전략 글로 바꾸기. 데이터는 엔진이 만들고 LLM은 문장만.
- 기본 CPU 난이도, 기본 메타 기준(상위 20/40) 같은 세부 설정.
