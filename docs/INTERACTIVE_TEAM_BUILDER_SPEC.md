# Interactive Team Builder 명세 (Phase 1)

화면: 앱 `팀 워크스페이스` (`/workspace`) 왼쪽·가운데 열. 코드: `app/lib/pages/workspace_page.dart`, `app/lib/workspace_state.dart`,
백엔드 `workbench.fast`.

## 구현됨

| 요구 | 구현 |
|---|---|
| 한 번의 클릭으로 교체 | 교체 추천 카드의 "이 후보로 교체" (추천 세트 적용) |
| 기존 세트 유지·추천 세트 적용 선택 | 추가는 기본(사용률) 세트, 교체 추천은 추천 세트, 세트 편집은 기존 편집기 |
| 변경 전후 차이 | 분석 섹션마다 직전 결과와 해시가 다르면 "방금 바뀜" 표시 |
| Undo / Redo | 워크스페이스에서 한 편집(추가·교체·빼기·세트 편집 1회 세션) 60단계 |
| 팀 복제 | 기존 `TeamNotifier.duplicate` |
| 포켓몬 잠금 / 기술·도구·특성·성격·능력 포인트 잠금 | 슬롯 아이콘 · 메뉴. 잠긴 항목을 편집기에서 바꾸면 되돌리고 안내 |
| 저장·이전 버전 복원 | 팀은 기기 저장(기존). 되돌리기로 이전 상태 복원 |
| 즉시 갱신 항목 | 규칙, 전략 연결성, 속도·속도 조작·선제기, 타입 약점, 화력 균형, 역할, 메타 위협, 정적 선봉, 메가 선택지 |
| 응답 속도 | 측정: 서버 함수 23ms(캐시 없음), HTTP 반복 7ms, 첫 호출 243~292ms |

## 섹션과 근거

| 섹션 | 계산 |
|---|---|
| 규칙 점검 | `workbench.legality` (learnset, 특성 목록, 도구·성격 표, 메가스톤, 능력 포인트, 같은 종·도구) |
| 전략 연결성 | `strategy.analyze` 태그 + `workbench.integrity` (순풍 수혜자가 이미 빠름, 빠른 트릭룸 시동, 느린 수혜자 부족, 날씨 충돌, 아군 광역기, 메가 후보 여러 마리, 역할 4마리 이상 중복) |
| 속도 | 실수치, 순풍 시 2배, 속도 조작 기술, 공격 선제기 |
| 타입·화력 | `engine.analyze_team` |
| 메타 위협 | 랭커 순위 상위 20종 대표 세트와의 정적 상성 하위 5 |
| 선봉 | `guide.team_guide` 정적 선봉 |

- 슬롯 순서 바꾸기(드래그), 편집 세션 단위가 아닌 필드 단위 Undo
- 서버 측 팀 버전 이력(현재는 기기 저장 + 되돌리기)
- 메가 후보 운영 계획 편집(어느 상대에 누구를 메가로)
