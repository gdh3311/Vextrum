## 2. 현재 알고리즘의 문제 (측정)

팀 자동 구성은 (1) 빔 탐색 초안 → (2) 짧은 모의전 경주 → (3) 멤버 교체 → (4) 최종 선택 순서다.
(1)의 순위를 정하는 `auto_team._score`는 사람이 정한 가중치의 합이다: 메타 상성 범위 ×0.55, 약점 압박, 역할 다양성 ×1.25, 동료 채용 ×0.4,
인기·랭커 쌍 보너스, 전략 요구, 날씨 충돌, 메가·도구 제한.

자동 연구 DB의 팀 6.5만 개(160만 판)로 '이 점수가 실제 승률을 맞히는가'를 쟀다. 종 구성 단위로 학습 80% / 보류 20%를 나눴다.

| 점수 | 보류 팀 12,606개 (24판 이상) 실제 승률과 순위 상관 | 그 점수 상위 10% 팀의 실제 승률 |
|---|---|---|
| 기존 초안 점수 `_score` | **−0.146** | 61.5% |
| 워크스페이스 정적 점수 | 0.03 | — |
| 학습 모델 (이 작업) | **0.597** (전체 보류 0.571) | **80.6%** |
| (전체 평균) | | 72.8% |

48판 이상 팀 80개에서는 학습 0.891, 초안 −0.627.

해석: 빔 탐색은 실제 승률과 **반대 방향**으로 약하게 상관된 점수를 최대화하고 있었다. 진단에서 탐색 예산을 2배로 늘려도 보류 성능이 유의하게 오르지 않았던 것
(+2.6%p, −3.1 ~ +8.3)과 일치한다. 모의전 경주가 그 뒤를 수습했지만, 경주에 올라오는 후보 자체가 잘못 고른 것이었다.

## 3. 엔진 v7

- `backend/app/team_model.py`: `logit p = b + Σθ_종 + Σα_(종,종)` (같은 팀 쌍, 60팀 이상 함께 나온 쌍만 840개). 이항 로지스틱 회귀 + L2, 순수 파이썬 AdaGrad
  (numpy 불필요). 학습 22초, 결과 `backend/app/team_model.json` 57KB를 앱에 동봉.
- 상대 항 β는 없다: 자동 연구의 상대는 무작위 메타 팀이라 상수로 흡수된다 (Sahovic의 '메타 대상' 설정과 같다).
- `auto_team._score` / `_extensions`: 모델이 있으면 **품질 항목**(상성 범위·약점 압박·다양성·동료)을 `모델 로짓 × 40`으로 바꾼다.
  **조건 항목**(전략 요구, 날씨 충돌, 메가·도구 제한, 랭커 베끼기 감점, 개성 설정의 인기·랭커 쌍 가중)은 그대로 둔다.
- 모델이 없으면 v6와 같다. 증분 점수와 전체 점수가 같음을 테스트로 고정 (`tests/test_team_model.py`).

## 4. 검증

`tools_bench_versions.py quick balanced v6 v7 v7-x2`: 12조건마다 각 엔진으로 만들고, 탐색에 쓰지 않은 시드(챔피언 40판, 마스터볼 60판·5스타일)에서
같은 상대·난수로 싸워 짝지은 차이의 95% 신뢰구간을 낸다. 연구 DB는 빈 복사본(연구 시드 없음).

| | v6 | **v7** | v7-x2 (모델 비중 2배) |
|---|---|---|---|
| 챔피언 보류, 팀 평균 | 63.8% | **68.3%** | 66.6% |
| v6 대비 차이 (95%) | — | **+4.4%p (+0.5 ~ +8.4) 더 나음** | +2.8%p (−1.2 ~ +6.8) 판단 불가 |
| 마스터볼 보류, 팀 평균 | 62.7% | **66.6%** | 66.7% |
| v6 대비 차이 (95%) | — | **+3.8%p (+0.6 ~ +7.1) 더 나음** | +3.9%p (+0.5 ~ +7.4) 더 나음 |
| 조건별 최고 팀 (챔피언 / 마스터볼) | 69.5% / 66.4% | **73.5% / 70.4%** | 72.1% / 69.9% |
| 빌드 시간 | 39.9초 | 39.5초 | 38.0초 |
| 팀 / 서로 다른 팀 / 종 | 30 / 26 / 37 | 32 / **29** / **41** | 30 / 26 / 41 |
| 순풍 가족 비율 | 16/30 | **8/32** | 9/30 |

판정: v7은 같은 시간에 두 보류 리그 모두 하한 > 0으로 더 강하고, 조건별 최고 팀도 오르며, 다양성도 늘었다(순풍 쏠림 절반).
모델 비중 2배는 더 낫지 않아 1배를 쓴다. **v7을 기본 엔진으로 채택** (`auto_team.build`, API 기본값). v6은 비교용으로 남긴다.

## 5. 한계

- 학습 데이터는 대부분 이전 시뮬레이터 버전과 하이퍼볼 CPU 조종(내 팀은 탐욕 판단)으로 쌓였다. 모델은 '이 앱의 모의전에서 이기는 팀'을 배운다. 실제 랭크전 승률이 아니다.
- 종 단위 모델이다. 같은 종의 세트 차이(도구·기술)는 반영하지 않는다. 세트 특징을 넣으면 세트 최적화에도 쓸 수 있다 (다음 단계).
- 연구 DB에 거의 없는 종(조커)은 θ=0으로 중립 처리된다. 조커 모드에서는 모델이 근거 없이 밀어내지 않지만 끌어올리지도 못한다.

## 6. 세트 특징 실험 (1.20.1) — 채택하지 않음

`team_model.py` 에 멤버별 세트 항을 더했다: `γ_(포켓몬, 도구) + Σ δ_(포켓몬, 기술) + ε_(포켓몬, 특성)`.
멤버마다 더해지는 항이라 한 마리 증가분은 여전히 정확히 계산된다 (테스트 고정). 60팀 이상 나온 특징만 써서 723개.
연구 DB의 종별 세트 가짓수는 중앙값 4, 최대 34 (golisopod).

오프라인 (같은 분할, 보류 24판 이상):

| 모델 | 처음 보는 종 조합 순위 상관 | 상위 10% 실제 승률 | 로그 손실 | 같은 6종 안에서 세트 차이 상관 (979 구성) |
|---|---|---|---|---|
| 종 + 쌍 (동봉) | 0.571 | 80.0% | 0.5651 | 0 (구분 못 함) |
| + 세트 (L2 2e-4) | 0.583 | 80.1% | 0.5648 | **0.153** |

L2 를 1e-3, 4e-3 로 바꿔도 거의 같았다.

보류 전투 벤치 (`TEAM_MODEL_ALT=종 모델 tools_bench_versions.py quick balanced v7-alt v7`, 4장과 같은 조건):

| | 종 모델 | 세트 모델 | 차이 (95%) |
|---|---|---|---|
| 챔피언 보류, 팀 평균 | 68.3% | 66.8% | −1.4%p (−5.1 ~ +2.3) 판단 불가 |
| 마스터볼 보류, 팀 평균 | 66.6% | 66.7% | +0.2%p (−2.8 ~ +3.1) 판단 불가 |
| 조건별 최고 팀 (챔피언 / 마스터볼) | 73.5% / 70.4% | 72.0% / 71.5% | |
| 서로 다른 팀 | 29 / 32 | 31 / 33 | |

판정: 세트 차이를 구분하는 능력은 생겼지만 실제 팀 성능은 유의하게 달라지지 않았다. '유의한 개선만 유지' 원칙에 따라
**동봉 모델은 종 모델 그대로** 둔다. 코드(세트 특징, `python -m app.team_model --sets`, 벤치 스위치 `-alt` + `TEAM_MODEL_ALT`)는 남긴다.
가능한 이유: 초안 단계의 세트 후보가 종마다 몇 개뿐이라 고를 여지가 작고, 벤치는 세트 조정(`tune`)을 끈 상태다.
세트 조정 단계에서 모델을 쓰거나 표본을 늘린 벤치가 다음 확인 거리다.

## 7. 세트 조정 단계에 모델 사용 실험 — 채택하지 않음

`set_tuner.Tuner(model=세트 모델)`: (1) 연구 전적에서 학습된 도구·기술 한 개 교체 중 모델이 높게 보는 것을 멤버마다 최대 2+2개 후보로 더하고,
(2) 시뮬레이션에 올릴 후보 순서를 '계산 점수 순위 + 모델 증가분 순위'로 정한다. 채택은 기존과 같이 시뮬레이션이 한다.
기본값(model=None)은 기존과 같다. 멤버별 기존 후보는 중앙값 7개라 8개 제한에 걸리는 멤버는 36%뿐이다.

`tools_bench_tuner.py 세트모델 quick`: 12조건 v7 팀(조정 없이 만든 최고 팀)을 두 조정기로 같은 시드에서 조정 → 보류 시드 200판씩.

| 12팀 평균 | 조정 없음 | 기존 조정 | 모델 조정 | 모델 vs 기존 (95%) |
|---|---|---|---|---|
| 챔피언 | 68.5% | 69.3% | 69.3% | +0.0%p (−0.4 ~ +0.5) 판단 불가 |
| 마스터볼 (5스타일) | 68.8% | 69.2% | 69.5% | +0.4%p (−0.0 ~ +0.8) 판단 불가 |

바뀐 팀: 기존 1/12, 모델 2/12 (시도 429 vs 457, 시간 78초 vs 81초). 세트 조정 자체의 효과가 +0.4~0.8%p로 작아서
모델이 바꿀 여지도 작다. 유의하지 않으므로 기본 조정기는 그대로 둔다.
