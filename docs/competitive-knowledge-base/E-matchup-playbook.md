# E · Battle Matchup Playbook

13개 상황의 전술 가설이다. 선봉은 필요한 역할을 설명하며, 괄호 안 포켓몬·기술은 그 세트를 실제로 장착했을 때만 적용한다. 상대의 숨겨진 기술·도구·교체는 가능한 경우의 수다. 앱 미구현 기술을 쓰는 플랜은 공식 게임에서 따로 확인한다.

| 상대 패턴 | 선봉 / 후발 요건 | 1턴 | 2~3턴과 교체 판단 | 승리 조건 및 실패 분기 |
|---|---|---|---|---|
| 1. 엘풍 순풍 | 선공 방해 가능자 + 즉시 압박, 후발에 순풍 또는 내구 | 속이기가 통하면 엘풍 방해와 동시 화력. 고스트 파트너·사이코필드·방어를 보고 타깃 수정 | 이미 순풍이 열리면 아군이 못 버티는 공격을 받아줄 후발로 넘기거나, 내 순풍이 역전시키는 구간만 전개 | 순풍 턴을 소모시키고 상대 에이스보다 많은 공격권 확보. 엘풍의 도발·앙코르에 방어/전개가 묶일 수 있음 |
| 2. 키키링 트릭룸 | 선공에 기대지 않는 특수/악 압박 + 도발·역트릭룸/보조, 후발 저속 옵션 | 테일아머가 살아 있으면 속이기로 막는 가정을 빼고 비선공 화력을 사용. 도발은 실제 기술·상대 멘탈허브 확인 | 전개가 성공하면 방어·교체로 유효 턴을 줄이거나 합법 역트릭룸. 선공으로 마무리할 때 키키링 잔존 여부 확인 | 시동 차단 또는 저속 에이스 고립. 공식 실기의 `봉인+트릭룸`은 앱 재현에서 제외 |
| 3. 리자몽Y + 이상해꽃 | 바위/단일 압박 + 수면 내성·안전한 피벗, 후발 날씨 | 상대 메가와 해가 켜질 행동 순서를 가정하고 바위 위협. 이상해꽃의 수면가루 타깃 내성을 확인 | 앞에서 날씨 싸움에 질 경우 후발 잔비 등으로 덮고 반격. 상대의 와이드가드 가능성이 있으면 단일 기술을 섞음 | 가뭄 시동 또는 엽록소 수혜를 먼저 끊기. 비를 한 번 깔았다고 다음 턴의 가뭄을 배제하지 않음 |
| 4. 패리퍼 비 | 풀/전기 또는 물 흡수 + 단일 화력, 후발 날씨·풀 | 패리퍼의 와이드가드 가정과 물·전기 유도 유무를 확인. 브리두라스가 바로 일렉트로빔을 쓸 수 있으면 선봉 내구 체크 | 패리퍼를 일찍 내보낸 판에서 상대가 다시 들어올 수 있는 HP를 추적하고 후발 날씨는 상대의 날씨 공개 뒤 사용 | 비 수혜의 행동 횟수를 줄이고 브리두라스/쓱쓱을 상성으로 막기. 날씨에서 우위여도 단일 집중 피해를 고려 |
| 5. 마기라스 + 몰드류 | 격투/물 + 땅 대응·가능하면 와이드가드, 후발 날씨 | 스톤샤워에 와이드가드 기대가 있어도 10만마력·아이언헤드 같은 단일 분기 준비 | 모래를 덮을 수 있다면 상대 마기라스 재등장에 맞춰 늦게 쓰기. 몰드류의 기합의띠는 모래로 제거된다고 가정하지 않음 | 모래헤치기 속도 보너스를 끊고 단일 KO. 준수한 특방의 바위 마기라스에게 특수만 몰지 않기 |
| 6. 브리두라스 지구력 | 특수 격투/땅 후보 + 상대 비 또는 상태 견제 | 지구력을 여러 번 올리는 약한 물리 공격 대신 실질 피해 있는 한 수. 일렉트로빔 선후와 방어 가능성 계산 | 비 또는 랭크 요인을 제거하고 특공 상승도 함께 확인. 실제 장착한 흑안개 등을 쓸 때 아군 상승도 초기화됨 | 방어 상승에 덜 영향을 받는 기술로 마무리. 앱 도감에 없는 바디프레스로 반격을 가정하지 않음 |
| 7. 드래펄트 고속 | 페어리/강철 또는 악 압박 + 스피드 조절 | 고스트 때문에 일반 속이기 무효. 물리/특수와 도구 가설을 보고 피격 역할을 정함 | 드래곤·고스트 기술에 들어올 후발을 분리하고, 속도 장악 후 상성 공격. 대타가 있으면 한 번에 KO 확정 금지 | 고속 핵심 먼저 정리한 뒤 아군 에이스 행동 보존. 드래곤애로의 더블 타깃은 앱 근사에 의존하지 않음 |
| 8. 어흥염 + 고내구 밸런스 | 특수 딜러 + 위협에 안전한 파트너, 후발 중립 피벗 | 위협·속이기를 피할 루트와 막말내뱉기 타깃 확인. 두 포켓몬이 모두 물리 약화에 걸리지 않게 배치 | 강제 교체가 예상되면 스위치 인의 상성까지 보고 타깃을 고름. 방어에 같은 타깃 몰아 손실 내지 않기 | 위협 교체 횟수를 줄이고 남은 높은 화력으로 교체 뒷자리를 압박 |
| 9. 사이코필드 + 카디나르마 | 악 타입 또는 와이드가드 + 단일 압박, 후발 필드 | 접지 와이드포스는 광역으로 대비. 와이드가드는 아머캐논 같은 단일 분기가 남음 | 고릴타 등으로 필드를 빼앗을 때 상대 에써르 재등장과 진입 순서 계산. 내 속이기를 쓸 수 있는 목표 재확인 | 와이드포스 조건을 끊고 카디나르마를 먼저 정리. 에써르 날따름으로 단일 공격 타깃이 바뀔 수 있음 |
| 10. 에써르 + 고화력 특수 | 광역 또는 특수 내구 + 단일 마무리, 후발 반감 | 광역은 날따름 영향을 받지 않으나 개별 방어·와이드가드 점검. 사이코필드가 없어도 날따름은 남음 | 두 마리가 같은 대상에 실제로 행동할 수 있을 때만 집중. 빛의장막이 유효하면 전개 턴을 확보 | 유도 요원과 에이스 중 하나를 잃게 한 뒤 통제. 암컷과 수컷의 기술 목록 구별 |
| 11. 그래스+사이코 혼합 | 유효한 중립 기술 + 마지막 필드 교체 요원 | 초기 특성 발동 순서를 기록. 현재 필드에서 선공기 사용이 가능한지 판정 | 상대 필드 요원의 후발 가능성에 맞춰 내 시동자 교체. 지진 대신 단일 땅이 유리한지 다시 확인 | 유리한 필드를 필요한 턴에 유지하고, 자기 공격의 강화·선공을 동시에 잃지 않기 |
| 12. 위협 반복 | 특수 + 오기/승기 또는 하락 내성, 후발 특수 보강 | 물리 양쪽 선봉 지양. 오기/승기가 실제 특성으로 장착되어 있는지 확인 | 위협 재등장 경로를 끊고, 체력보다 타이밍이 중요한 랭크 하락을 계획. 기술 특수·물리 분류 확인 | 상대가 안전하게 교체를 반복하기 전에 특수 타격으로 제거 또는 교체 비용 강제 |
| 13. 화상+리플렉터 | 특수 중심 + 불꽃/근성 또는 벽 대응, 후발 수적 우세용 딜러 | 도깨비불 타깃의 타입·흡수·필드 상태를 확인. 두 물리 딜러 동시 노출 최소화 | 리플렉터 턴을 소모하거나 실제 보유한 위협으로 반격. 앱에서 지원이 불완전한 벽 철거 기술은 실기 확인 | 물리 약화가 이기는 조건이 되지 않도록 특수 축을 유지. 화상 상태에서 급소만으로 피해 반감이 해결된다고 가정하지 않음 |

## 가이드가 응답에 붙일 조건

- **합법 행동**은 이번 4선출과 현재 필드, 기술·도구 보유 여부, 보호 효과, 우선도부터 검사한다.
- **조건부 승리**는 예를 들어 기습 대상이 공격기를 고를 때만 성립하며, 성공한 뒤 실제 KO가 되는지도 따로 표시한다.
- **추천 선출**은 상대 6마리와 내 세트가 입력된 뒤 후보별로 동일 조건의 비교를 수행한다. 1~4판 관측 예시는 연습에서 재생할 수 있는 샘플로 사용한다.

근거는 [정확도와 예외](A-master-reference.md), [M-C 대회 사례](C-current-meta.md), [검증되지 않은 메커니즘](F-unverified.md)에 있다. 턴별 운영은 이 근거 위에서 만든 추정이며, 실제 사용자 파티 6마리와 상대 6마리가 없으면 특정 선출에 확정 우위를 부여하지 않는다.
