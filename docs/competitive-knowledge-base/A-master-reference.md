# A · Vextrum Master Reference

확인일 2026-11-14 KST. 공식 게임은 **Pokémon Champions**이며 Nintendo 업데이트 이력의 Switch 최신 표기는 **1.2.2**다. **Vextrum 1.18.0 베타**는 이 게임의 데이터를 분석하고 로컬에서 배틀을 근사하는 도구다. 공식 게임은 스카우트·포켓몬 HOME 방문과 VP/트레이닝 티켓으로 특성·기술·능력치를 준비한다. Vextrum은 세트 편집, 팀 분석, 텍스트 실습과 CPU 모의전을 제공한다. [공식 게임 소개](https://champions.pokemon.com/en-us/gameplay/) · [스카우트·트레이닝](https://champions.pokemon.com/en-gb/pokemon/) · [Nintendo 업데이트 이력](https://en-americas-support.nintendo.com/app/answers/detail/a_id/71525/p/897) · [Vextrum 소스](https://github.com/gdh3311/Vextrum/tree/v1.18.0-beta)

## 기술과 특성

아래는 앱 코드에서 확인한 분류다. 위력, 명중, PP, 타깃, 방어 플래그는 `moves.json` 필드별 출처를 따른다. 단일 공격 중 일부는 공식 게임에서 아군을 지정할 수 있다. 앱은 일반 단일 공격으로 아군을 고르는 선택지를 제공하지 않는다. 지진·파도타기 등 `allAdjacent`는 아군에게도 들어간다.

| 묶음 | 앱 처리 및 운영 조건 |
|---|---|
| 방어·판별 / 와이드가드·패스트가드 | 개별 방어·연속 성공 감소, 광역·선공 차단. 페인트, 접촉 관통 특성, 자가/아군 대상 효과는 구별. 광역기 대상이 하나만 남는 상황도 전용 가드와 0.75 피해 판정은 별개 |
| 속이기 / 앙코르·도발 | 속이기는 앱에서 등장 플래그가 맞는 첫 행동 때 선택. 노말 무효, 정신력, 선공 차단을 별도로 적용. 앙코르로 기술 제한, 도발로 변화기 제한. 방어 직후 앙코르는 해당 기술과 상대 도구 확인 필요 |
| 봉인·사슬묶기 | 앱 도감에 있지만 시뮬에서는 효과 미구현. 공식 실전 대응 옵션으로는 `봉인+트릭룸`을 고려하되 앱 결과로 평가하지 않음 |
| 날따름·분노가루 | 상대 단일 타깃 유도, 광역에는 영향 없음. 분노가루는 공격자가 풀 타입이거나 방진·방진고글이면 무시할 수 있음 |
| 순풍·트릭룸·속도 하락 | 순풍 사용 턴 포함 4턴, 트릭룸 5턴이며 재사용 시 해제. 트릭룸은 같은 기술 우선도 안의 순서를 뒤집음. 얼다바람·일렉트릭네트·암석봉인은 명중과 스피드 하락 방어를 확인. 전기자석파는 마비 면역·가드·타입 상성도 고려 |
| 지진·파도타기 | 양쪽 인접 타격. 아군 부유/비행·흡수·방어와 함께 확인. 그래스필드 지진 반감은 목표 접지 기준 |
| 열풍·눈보라·스톤샤워·탁류·하이퍼보이스·매지컬샤인·분화 | 상대 광역. 눈보라는 눈에서 명중 보정, 분화는 남은 HP, 일부 소리 기술은 방음과 대타 상호작용. 광역 막힘과 실제 2타 여부를 별도로 확인 |
| 칼춤·나쁜음모·벌크업·명상·도우미 | 앞의 두 기술은 공격 또는 특공 +2, 벌크업 공격·방어 +1, 명상 특공·특방 +1. 도우미는 같은 턴의 아군 공격에 적용할 때 의미가 있음 |
| 막말내뱉기·유턴·볼트체인지 | 막말내뱉기는 공격·특공 하락을 시도하며 반사·하락 특성을 고려. 유턴·볼트체인지는 유효한 타격과 후발이 있어야 교체. 막힘·전기 무효·유도로 상대 반응이 바뀔 수 있음 |

| 특성 | Vextrum 확인 범위와 실전 확인점 |
|---|---|
| 위협 · 정신력 · 심술꾸러기 | 위협은 등장 시 물리 압박을 낮춤. 정신력은 위협과 풀죽음 방지에 관여하며 고스트의 노말 무효와 다름. 심술꾸러기는 랭크 변화 방향을 반전. 오기/승기는 능력 하락 후 반격 압박 |
| 짓궂은마음 · 매직미러 | 선정된 변화기에 우선도 +1. 상대 악 타입 대상의 짓궂은마음 기술은 실패. 앱 매직미러는 구현된 일부 대상 변화기를 반사하므로 대상별로 확인 |
| 틀깨기 · 부유 | 틀깨기는 공격과 관련한 일부 상대 특성 무시. 부유는 땅 면역·비접지. 비행 타입과 사이코필드 자체의 보호 효과를 같은 종류의 특성으로 취급하지 않음 |
| 피뢰침 · 마중물 | 일반 전기/물 단일 기술의 유도 및 흡수·특공 상승. 광역 전체를 대신 맞는 선택지로 계산하지 않음 |
| 재생력 · 천진 | 재생력은 살아 있는 상태로 교체시 최대 HP 기준 회복. 천진은 관련 상대 배율을 무시하도록 앱에 구현되어 있으나 특수 기술별 참조 능력치와 랭크 조건은 확인점 |
| 지구력 · 가속 | 지구력은 맞았을 때 방어 상승. 다단 기술은 앱의 묶음 처리 때문에 실전과 달라질 수 있음. 가속은 조건을 충족한 턴 종료 시 스피드 +1 |
| 쓱쓱 · 엽록소 · 모래헤치기 · 눈치우기 | 비/쾌청/모래/눈의 각 유효 날씨에서 속도 ×2. 날씨가 바뀌거나 효과가 억제되면 배율을 다시 판단 |

## 날씨와 필드

지속 시간은 시동 턴 포함 앱 기준이다. 날씨와 필드는 별도 상태이며 각 범주에서는 마지막으로 성공한 효과가 덮어쓴다. 초기 등장 특성은 앱에서 스피드 내림차순이라 느린 쪽이 마지막에 덮는 경우가 있다. 즉시 교체·메가진화가 이미 일어난 턴은 개별 로그를 확인한다. 날씨는 기본 5턴, 해당 연장 바위 8턴. 필드는 기본 5턴, 그라운드코트 8턴. 접지 여부는 앱에서 비행·부유·소모 전 풍선 등을 확인한다.

| 효과 | 핵심과 실전 대응 |
|---|---|
| 쾌청 | 가뭄/쾌청, 불꽃 1.5배·물 ½, 솔라빔/솔라블레이드 준비 생략, 엽록소 속도. 메가리자몽Y+이상해꽃은 리자몽 메가 공개 전후 날씨와 강철/바위 압박을 나눠 대응 |
| 비 | 잔비/비바라기, 물 1.5배·불꽃 ½, 번개/폭풍 명중, 일렉트로빔 즉시 실행, 쓱쓱. 패리퍼를 후발까지 보존하면 상대 날씨를 다시 덮을 수 있음 |

## 데미지와 속도 검증

Vextrum의 `Engine.damage()`는 Lv.50 `floor(floor(22 × 위력 × 공격/방어) / 50) + 2`에 여러 보정을 곱하고 평균 난수 0.925를 사용한다. 기술별 참조 능력치, STAB 1.5(적응력 2), 타입 상성, 다중 타깃 0.75, 날씨·필드·벽·도구를 적용한다. `Battle._damage()` 및 `_attack()`은 랭크, 화상(기본 물리 ½), 도우미, 급소(일반 1/24, 1.5배), 0.85~1.0 연속 난수, 대타·방어·흡수·기합의띠 등을 이어서 처리한다. 일반 급소는 앱에서 벽 효과를 제거하는 데 쓰이지만 공격/방어 랭크를 원작과 동일한 방식으로 무시하는 정밀 모델까지는 검증되지 않았다. `lab.rng()`의 상하한은 평균값을 역산한 근사이며, 맞힐 확률이나 실전 KO 확률과 동치가 아니다.

**재현 예시.** 명랑 한카리아스 공격 32/스피드 32/HP 2, 도구 없음, 무보정 상태. 신중 어흥염 HP 32/특방 32/방어 2, 맹화, 도구 없음, 날씨·필드·벽 없음. 두 타깃 지진의 앱 평균은 **75.2%**, 근사 피해 범위 **69.1~81.3%**다. 대상이 방어·교체·회복·기합의띠 보정 없이 동일한 지진을 두 번 실제 맞는다면 모델 범위의 합은 100%를 넘는다. 그래스필드가 있거나 위협이 발동하거나 아군 보호가 필요한 상황에서는 다시 계산한다. 이 한카리아스의 앱 스피드는 169, 순풍에서 338. 명랑 최대 스피드 메가한카리아스Z는 같은 입력에서 223, 메가한카리아스는 158이다. 비교 상대의 특성·도구가 비공개일 땐 속도 우위도 조건부다. **1타와 생존 도구 예시.** [D](D-team-building.md)의 명랑 공격 32 포푸니크가 고집 HP 32·방어 2 대도각참에게 인파이트를 쓰면, 날씨·필드·벽·화상·랭크 변동이 없을 때 도구 없는 상대에게 앱 근사 **170~200%**다. 같은 상대가 로플열매를 지니면 **85~100%**가 되어 즉시 제거를 보장할 수 없다. HP가 가득 찬 기합의띠 장착 상대는 피해표가 100%를 넘어도 앱의 실제 턴 처리에서 버틸 수 있다. 피해 범위, 기술 명중, 행동 순서는 각각 확인한다.
