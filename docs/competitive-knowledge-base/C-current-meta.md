- M8 랭크는 **11월 4일 11:00~12월 2일 10:59 KST**, M-C다. 챔피언과 마스터볼 I~III는 11월 11일에 개방되었다. 몬스터볼·슈퍼볼·하이퍼볼·마스터볼과 챔피언의 표시를 구분한다. 초기화 직후 등급·보너스 매핑은 미확인이다. 일반 M8 배틀패스의 영어 게임 공지 종료 시각은 12월 1일 10:59 KST로 랭크 공지와 다르다. [M-C 공지](https://champions-news.pokemon-home.com/ko/page/816.html) · [M-C 스탠더드 셀렉트](https://champions-news.pokemon-home.com/ko/page/821.html) · [Nintendo 업데이트 이력](https://en-americas-support.nintendo.com/app/answers/detail/a_id/71525/p/897)
- 조사일 Vextrum 공급원 `season=M8`은 HTTP 400, `Current`는 HTTP 200을 응답했다. `Current` 응답의 가장 최근 보관 시즌은 M7이고, 날짜·순번이 다른 출처와 비슷해도 시즌과 동일 표본 여부를 단정할 수 없다. [순위 API와 필드 정의](https://championsbattledata.com/api_guide)

## Vextrum 모의전으로 확인한 범위

1.18.0 자동 구성에서 기본 표준 후보 3팀, 표준 비·트릭룸 후보를 각각 생성하고, 팀 선정과 보류 평가에 쓰지 않은 참가 코어 70종의 135판에서 비교했다. 상대 코어와 CPU 성향의 순서는 팀마다 동일했다. 승점률은 1승=1, 무승부=0.5다. [대조 코드](https://github.com/gdh3311/Vextrum/blob/v1.18.0-beta/backend/app/battle_lab.py)

|---|---:|---:|---|
| 기본 대도각참+메가요가램 1안 | 94-40-1 | 70.0% | 해당 별도 표본에서 트릭룸 활용 0회 |
| 기본 대도각참+메가요가램 2안 | 92-41-2 | 68.9% | 트릭룸 활용 2회 |

기본 선출 1안에서 사이코필드 상대 대표 조합은 관측 3경기였다. 그 조합을 새 사이코필드 상대 27판에 고정하니 16승 9패 2무, 기존 상성 선출은 18승 8패 1무였다. 상대별 후보와 재현 표본을 분리해서 읽어야 한다. 이 표는 공식 M8 대인전 승률을 제공하지 않는다.
