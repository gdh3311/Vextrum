# B · Pokémon Competitive Database

다음 명령은 설치된 Vextrum 소스와 로컬 데이터로 AI가 조회할 수 있는 UTF-8 JSON을 만든다. 기존 데이터 수집이 끝난 저장소 루트에서 실행한다. 공식 목록 및 Showdown 보정 정보를 가져올 때 인터넷을 사용한다.

```powershell
python tools/build_competitive_kb.py
```

| 파일 | 행 | 조회 기준과 근거 |
|---|---:|---|
| `manifest.json` | 1 | 수집 시각, 실제 앱 버전·커밋·정책, 소스 URL과 SHA-256, 범위 |
| `official-roster.json` | 262 | 앱 ID → 공식 참가 폼 코드·한국어 이름·전국도감 번호. 231개 고유 번호 |
| `pokemon.json` | 263 | 이름, 타입, 공식 참가 폼 매핑, Showdown 종족값/특성 슬롯, 앱 Lv.50 무보정 수치, 앱 습득 기술 ID, 메가 후보, 시즌별 순위, 합성 기본 세트·역할·근사 상성 |
| `moves.json` | 511 | 기술 ID → 앱 실사용 위력·명중·우선도, 참조 타깃·방어 플래그, PP 및 출처, 추가 효과, 앱 시뮬 처리 표시 |
| `abilities.json` | 216 | 영문명 → 한국어명, 효과 확인 범위, 해당하는 앱 포켓몬 ID. 앱 특성 사전에 없는 마중물 보충 |
| `items.json` | 162 | 영문명 → 한국어명, 알려진 앱 미구현 여부, 대응 메가 폼 |
| `megas.json` | 81 | 부모 ID, 전후 타입·종족값·특성·실수치 차이, 메가스톤, 역할·기술 후보, 공식 신규 허용 여부 |
| `m8-public-evidence.json` | 1 | 11월 13일 외부 표본의 상위 12종·공개 팀·코어 사례와 출처 |

`moves.json`의 410개 기술은 현재 앱 시뮬의 기술 게이트를 통과한다. 나머지 101개는 변화기 구현 누락, 자폭, 메타데이터 미확인 등으로 게이트를 통과하지 않는다. 게이트를 통과한 기술에도 부분 구현이 있다. 예를 들어 일반 공격으로 피해를 계산해도 부가 효과나 대상으로 아군을 고르는 규칙까지 구현했다는 보장은 없다. `moveAcquisitionMethod`는 `null`이라 기술머신·유전 여부를 따로 확인해야 한다. `canAffectAllyByTarget`과 `protectFlagShowdown`은 참조 타깃 규칙이다. `showdownChampionsDifferences`는 위력·명중·타입·우선도·타깃의 직접 비교이며 전체 상호작용 감사를 의미하지 않는다. `m8Stats`는 [선별한 외부 집계](m8-public-evidence.json)가 있는 포켓몬에만 채웠다.

`baseStatsShowdown`은 종족값, `appLevel50NeutralZeroSp`는 이미 Lv.50에 맞춘 무보정 실수치다. 예를 들어 한카리아스 종족값 `108/130/95/80/85/102`는 앱에서 `183/150/115/100/105/122`로 출발한다. 차이가 있는 폼은 `statDifferencesFromShowdownBaseline`을 확인한다. `normalAbilitiesShowdown`과 `hiddenAbilityShowdown`은 참조 도감 슬롯, `abilitiesInAppData`는 앱 목록이다. `competitiveAssessment`의 유불리는 M7 계열 상위 20종의 기본 세트와 비교한 1:1 근사 점수다. 파트너는 동료 순서이고, 방해 내성은 해당 타입이나 해당 특성을 실제 선택했을 때 적용된다. 트릭룸 가치는 아군·상대 실제 스피드와 우선도가 있어야 판정할 수 있다.

## 우선 검토 포켓몬

세트들은 대표적인 역할 예시다. 명시한 경우의 랭크 채용 수치와 VGC 팀시트는 [C](C-current-meta.md)에서 확인할 수 있다. 실제 능력 포인트는 목표 속도와 생존선에 맞춰 선택한다.

| 포켓몬 | 대표 역할과 세트 구성 | 시너지와 점검할 상대 |
|---|---|---|
| 포푸니크 | 곡예+하양허브, 인파이트·페이탈클로·방어·속이기. 명랑 또는 고집의 공격·스피드 투자부터 확인 | 인파이트의 랭크 하락·허브 소모 조건, 도구 없이 시작하는 경우와 구분. 사이코필드·테일아머와 고스트, 자체 속도 조작을 확인 |
| 한카리아스 | 까칠한피부, 지진·드래곤클로·스톤샤워·방어. 명랑 공격·스피드 후보 | 워시로토무와 지진 동반 가능. 그래스필드·얼음 기술·와이드가드를 보고 지진 이외의 합법 단일 땅 공격을 준비 |
| 고릴타 | 그래스메이커, 그래스슬라이더·우드해머·속이기·10만마력 후보 | 필드 재전개, 비의 물 공격 견제. 사이코필드에 밀리면 그래스슬라이더의 우선도·지상 선공기 조건이 바뀜 |
| 에써르 암컷 | 사이코메이커, 날따름·사이코키네시스·도우미·트릭룸 | 카디나르마의 와이드포스, 자체 트릭룸은 선택지. 앱 스냅샷 암컷 학습 목록에 와이드포스가 없으므로 수컷과 구분 |
| 패리퍼 | 잔비, 웨더볼·폭풍·와이드가드·순풍 또는 방어 | 브리두라스·대쓰여너·전기 흡수 요원. 전기 압박과 상대 날씨를 고려해 후발 재전개를 보존 |
| 브리두라스 | 지구력, 일렉트로빔·용의파동·러스터캐논·방어 | 잔비로 일렉트로빔 즉시 실행 조건을 만들고, 지구력으로 올라가는 방어 대신 특방을 압박하는 상대를 확인. 바디프레스·미러코트·메탈버스트를 임의로 추가하지 않음 |
| 어흥염 | 위협, 속이기·플레어드라이브·막말내뱉기·도우미 후보 | 특수 화력과 조합, 반복 교체로 아군 보호. 오기·승기·사이코필드·대도각참 기습 조건 확인 |
| 키키링 | 테일아머, 트릭룸·도우미·특수 공격 후보 | 선공기를 막아 트릭룸 요원 보호. 악 타입 상대와 트릭룸 역전, 봉인 보유 상대를 대비 |
| 인텔리레온 | 급류/스나이퍼 특수 고속 후보. 기술 표에서 도발·얼다바람 확인 | M-C 공식 참가이며 M8 배틀패스 보상. 선택률이나 입상 실적 없이 등급을 부여할 근거는 없음 |

앱 스냅샷의 시즌별 순위는 `publishedDoublesRankBySeason`, 세트 부위별 채용률은 `snapshotSetComponentRatesPct`에 있다. 기본 세트는 부위별 최빈 항목을 조합한 구성이고 실제 한 플레이어의 세트 여부는 공개 팀시트에서 확인한다.
