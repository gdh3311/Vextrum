## 재현 기록 최소 단위

- 규칙 확인은 동일 세트로 이펙트 하나만 바꾼 비교 매치 두 개부터 기록한다. 예를 들어 사이코필드 속이기는 접지·비접지 타깃, 정신력 유무, 아군 대상 여부를 따로 기록한다.
- 피해 계산에는 공격 전 HP, 화면에 표시된 상태·랭크·필드, 양쪽 세트, 기술 선택, 명중·급소·가드 결과를 포함한다. 시뮬레이터가 다단·명중·KO 중 어떤 부분을 계산했는지 분리해 저장한다.
- 새 메타 스냅샷이 오면 [B](B-pokemon-database.md) 내보내기를 다시 실행한다. 공식 규정이 바뀌면 생성기의 공식 목록 URL과 폼 매핑을 갱신하고, [C](C-current-meta.md)의 시즌 범위와 이전 대회 출처를 확인한다.
