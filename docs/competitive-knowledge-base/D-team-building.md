# D · Team Building Framework

**사용자 기본값**은 더블, 공격적인 초반 압박과 안전한 교체, 물리·특수 균형, 다수의 매치업에 통하는 선출, 특정 포켓몬 복제에 얽매이지 않는 조합이다. 트릭룸은 상대 트릭룸 해제나 일부 매치업의 보조 선택지로 우선 검토한다. 이전에 쓴 라이츄·메타그로스·어흥염·워시로토무·엘풍·몰드류·한카리아스·보만다·리자몽·이상해꽃·패리퍼·에써르·카디나르마·고릴타·삼삼드래·포푸니크는 탐색 후보이며 현재 보유나 선호 세트로 저장할 근거는 없다.

## 6마리 → 4마리 → 첫 3턴

| 평가 기준 | 저장할 근거 |
|---|---|
| 1 공격 커버리지 | 메타 위협별로 실제 가진 단일·광역 타격, 아군 피해·면역·명중 조건 |
| 2 물리/특수 | 전체 6마리 비율과 각 4선출의 화력. 위협 두 번·화상처럼 물리 축을 무력화하는 상태도 별도 |
| 3 스피드 | 자연 속도, 순풍, 날씨, 마비, 선공, 스카프, 트릭룸에서 아군·상대의 실제 수치와 동속 |
| 4 속이기/선공 대응 | 고스트·정신력·가드·방어·필드 변경·테일아머 등 서로 다른 답과 해당 보유 여부 |
| 5 위협/화상 | 불꽃·특수 화력·오기/승기·클리어바디류. 랭크 하락을 막는 것과 오히려 이득 보는 것을 구별 |
| 6 날씨 | 열고 덮을 수단, 상대가 나중에 덮는 경우의 대안, 시동/수혜 동반선출 및 실제 활용 |
| 7 트릭룸 | 전개 저지, 전개된 뒤 생존, 종료 턴 역습. 봉인 등 앱 미구현 요소는 실기에서 평가 |
| 8 메타 대응 | 표본 출처와 시점, 주요 상대 최소 2가지 세트 가정, 숨겨진 도구·교체 시 실패 조건 |
| 9 선봉 다양성 | 공격·미러·수비를 대상으로 선봉·후발을 각각 제시. 상대 6마리에 따라 바뀌는 조건 기록 |
| 10 역할 압축/중복 | 순풍+공격, 위협+피벗처럼 한 자리의 복수 역할과 함께 뽑지 못하면 사라지는 역할 |
| 11 메가 슬롯 | 진화 전후 특성/스피드, 후발 메가 가능성, 두 스톤을 넣으면 잃는 도구 비용 |
| 12 패배 패턴 | 선출 누락, 시동 실패, 위협·벽·필드 충돌, 표본에서 본 실제 패배 턴과 대안 |

1. 엔트리 검증에서 도감 번호·도구·기술·특성·SP·스톤을 점검한다. `공식 등록 가능`, `앱 계산 가능`, `앱 효과 검증`을 각각 유지한다.
2. 상성·역할 계산으로 선출 후보를 좁힌다. 각 4마리에 승리 조건의 시동·수혜·교체 또는 방어가 포함되는지 확인한다. 6명 중 보유 기술을 가져와도 그 포켓몬이 대기라면 이 판의 행동으로 제안할 수 없다.
3. 선봉 후보는 상대 6마리→예상 선출 가설을 여럿 놓고 비교한다. 1턴은 상대 바로 공격/방어/교체/전개를, 2~3턴은 필드·스피드 변화와 후발 진입을 본다. 동시 집중 공격은 둘 다 그 턴에 필드에 있고, 먼저 쓰러지거나 행동이 막히지 않는 경우만 계산한다.
4. 같은 상대·같은 초기 난수로 원안과 변경안을 비교한다. 상대 코어 단위로 구간을 계산하고, 사용할 선출을 확정한 뒤 안 본 코어에서 재평가한다. 이긴 판과 진 판의 첫 2턴을 하나씩 재생한다. 근거가 얇으면 `관측 예시`; 장점이 반복되면 `모의전 재현`; 사용자 실기 기록이 있으면 `실전 관측`을 붙인다.
5. 데미지 자료에는 공격·방어 세트, 레벨, SP, 성격, HP, 랭크, 필드, 대상 수, 조건부 기술 가능 여부를 보관한다. 1타는 최소 피해/생존 도구·명중을, 2타는 두 공격의 합과 회복·방어·턴 순서를 검토한다. 적은 실기 표본으로 상대 세트 빈도를 업데이트하지 않는다.

## 사용자 성향에 맞는 선봉 예제

위 6마리는 선출을 시험할 수 있는 초안이다. 다음 세트는 Vextrum의 팀 합법성 검사와 시뮬 지원 집합을 통과했다. 포인트 순서는 **HP/공격/방어/특공/특방/스피드**다. 공식 게임에서의 최적 배분·사용자 보유 여부는 추정 상태다.

| 포켓몬 | 도구 · 특성 · 성격 | 포인트 | 기술 |
|---|---|---|---|
| 엘풍 | 기합의띠 · 짓궂은마음 · 겁쟁이 | 2/0/0/32/0/32 | 순풍·문포스·앙코르·방어 |
| 보만다 → 메가보만다 | 보만다나이트 · 위협→스카이스킨 · 겁쟁이 | 2/0/0/32/0/32 | 순풍·하이퍼보이스·용성군·방어 |
| 워시로토무 | 자뭉열매 · 부유 · 조심 | 32/0/2/32/0/0 | 볼트체인지·하이드로펌프·10만볼트·방어 |
| 어흥염 | 울퉁불퉁멧 · 위협 · 신중 | 32/0/14/0/20/0 | 속이기·막말내뱉기·플레어드라이브·도우미 |
| 포푸니크 | 하양허브 · 곡예 · 명랑 | 2/32/0/0/0/32 | 인파이트·페이탈클로·속이기·방어 |
| 고릴타 | 기적의씨 · 그래스메이커 · 고집 | 32/32/2/0/0/0 | 그래스슬라이더·우드해머·속이기·10만마력 |

| 선봉 | 후발 예시 | 승리 플랜 |
|---|---|---|
| 엘풍 + 메가보만다 | 워시로토무 + 어흥염 | 순풍을 앞세워 특수 압박. 위협 이후 보만다를 진화할 시기와 얼음/바위 교체 경로 확보 |
| 어흥염 + 워시로토무 | 고릴타 + 메가보만다 | 위협과 피벗으로 상대 메인 공격수를 노출시켜 풀·물·특수 화력을 차례로 투입 |
| 고릴타 + 포푸니크 | 워시로토무 + 엘풍 | 필드·속이기 차단부터 확인하고 빠른 두 공격으로 시동 요원을 압박. 초반 급소나 페이탈클로 상태 이상에 의존하지 않음 |

이 초안은 땅을 받는 보만다·부유 워시로토무와 격투·풀 단일 압박을 갖췄다. 기술 기준으로 물리 주력 포푸니크·고릴타와 특수 주력 보만다·워시로토무가 있다. 비·날씨를 직접 덮을 기술과 와이드가드, 트릭룸을 즉시 해제할 기술은 없으므로, 이들 매치업에서는 압박·교체·앙코르·턴 소모가 필요하다. 상대 사이코필드에 속이기 3자리를 그대로 내면 역할 중복이 약점이 된다. 보만다는 메가진화 전 위협을 한 번 더 쓸 가치와 속도를 지금 올릴 가치를 비교한다.

2026-11-14 마스터볼 CPU로 각 상황 18판씩, 같은 상대와 초기 난수로 비교했다(`audit`, 시드 `15487011`, 상대 성향 6가지). 순서는 **승-패-무**다. 선출마다 아군 팀은 같았다.

| 상대 | 조합 고정 | 상성에 따라 선출 | 상대 코어 수 |
|---|---:|---:|---:|
| 순풍 · 엘풍+보만다 선봉 | 10-8-0 | 9-9-0 | 16 |
| 모래 · 어흥염+워시로토무 선봉 | 8-10-0 | 9-8-1 | 2 |
| 비 · 고릴타+포푸니크 선봉 | 13-4-1 | 15-3-0 | 6 |

세 조합 모두 훈련용으로 실행 가능하다. 이 표본에서 선출을 고정해야 할 정도의 우위는 확인하지 못했다. 특히 모래는 코어 2개가 반복된 표본이다.

## 아키타입별 승리 조건과 실패 패턴

| 아키타입 | 선봉·시너지 | 승리 조건 | 실패 패턴과 대응 |
|---|---|---|---|
| 순풍 공격 | 엘풍/패리퍼 + 실제 턴을 앞당길 공격수 | 4턴 창에서 상대 고속 핵심을 먼저 제거 | 트릭룸·미러 순풍. 후발도 우선도·속도로 마무리할 수 있는지 확인 |
| 트릭룸 | 키키링/에써르·메가입치트, 유도나 속이기 대응 | 전개 직후 저속 화력 2마리 투입 | 전개 방해 또는 속도 반전 실패. 시동 요원과 후발을 따로 잡거나 실효 턴 소모 |
| 안티 트릭룸 | 악 타입·도발/앙코르·합법 봉인/역트릭룸 | 시동을 차단하거나 역방향 턴을 버티고 속도 우세 회수 | 정신허브·유도·테일아머. 한 가지 차단기만 전제하지 않음 |
| 가뭄 | 메가리자몽Y + 이상해꽃 | 불꽃·엽록소로 행동권 확보 | 비·바위·광역 가드. 해를 다시 덮을 수단과 단일 불꽃/풀 확보 |
| 비 | 패리퍼 + 브리두라스/쓱쓱 공격수 | 시동 직후 강화 물 기술 또는 일렉트로빔 | 패리퍼가 빠지는 4선출, 상대 날씨·마중물. 비 핵심 동반률부터 기록 |
| 모래 | 마기라스 + 몰드류 | 모래헤치기 속도로 단일 땅·광역 바위 운영 | 비 덮기·물 및 격투. 기합의띠는 날씨로 무조건 깨진다고 가정하지 않음 |
| 눈 | 알로라 나인테일 + 눈보라/얼음 에이스 | 방어 보정과 오로라베일 창 활용 | 선제 날씨 변경·강철·도발. 눈이 없는 오로라베일을 명령하지 않음 |
| 사이코필드 광역 | 에써르 + 카디나르마 | 접지 와이드포스와 단일 커버리지 | 악 타입·와이드가드·필드 덮기. 선공이 막히는 아군을 함께 점검 |
| 그래스필드 순환 | 고릴타 + 피벗·물/땅 견제 | 속이기·회복·그래스슬라이더 재사용 압박 | 필드 덮기·강철·비행. 아군 지진의 접지 피해 재계산 |
| 위협 교체 | 어흥염/보만다 + 내구·특수 딜러 | 물리 방해 후 안전한 교체로 자원 우위 | 오기·승기·클리어바디. 상대가 랭크 하락을 원할 때 특수 타격으로 대응 |
| 고내구 밸런스 | 밀로틱/워시로토무 + 위협/회복 | 피격·교체 후 보존한 에이스로 유리한 후반 | 도발·집중 공격·벽과 PP. 앱에서 공식 시간 판정까지 검증 불가 |
| 초고속 하이퍼오펜스 | 드래펄트/포푸니크 + 서로 빈 상성을 채우는 빠른 딜러 | 초기 2턴 이내 수적 우세 | 선공·트릭룸·방어. 내구 스위치 하나와 필드 대응을 남김 |
| 혼합 날씨 | 상성이 다른 상대에 맞춰 시동자와 수혜를 묶어 선출 | 서로 다른 4선출로 다른 날씨 플랜을 수행 | 같은 4마리에서 날씨끼리 덮어 수혜가 사라짐. 순서와 전환 이유가 없으면 분리 |
| 혼합 필드 | 고릴타/에써르 중 어느 쪽이 마지막에 들어오는지 관리 | 공격용 필드 또는 선공 차단을 해당 턴에 확보 | 필드 바꾸는 턴에 자기 선공기·광역 강화가 사라짐. 두 필드 동시 효과를 계산하지 않음 |

대회의 실제 혼합 속도·이중 메가 예는 [그단스크 우승 팀시트](https://standings.limitlessvgc.com/0044/player/0117/teamlist)와 [준우승 팀시트](https://standings.limitlessvgc.com/0044/player/0340/teamlist)에서 볼 수 있다. 각 선봉을 평가할 때는 [E](E-matchup-playbook.md)의 적용 조건을 같이 확인한다.
