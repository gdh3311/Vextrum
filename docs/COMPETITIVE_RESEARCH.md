## 3. 기능별 정리 — 이미 있는 것과 Vextrum이 더 깊게 할 것

| 차별화 항목 | 이미 하는 곳 (확인된 범위) | Vextrum의 통합 방식 |
|---|---|---|
| A. 설명 가능한 교체 | Team Analyzer(팀 전체 점수 변화), Battle Data("왜 맞는지") | 해결·새로 생기는 약점, 역할·속도 조작·승리 조건 변화를 계산으로 보여 주고, 정적 점수와 **모의전 검증 결과를 따로** 표시 |
| B. 실시간 팀 진화 | 대부분 정적 분석이 편집에 따라 바뀜 | 편집마다 빠른 분석 + 직전 버전과의 차이 + 실행 취소/다시 실행 + 잠금. 이전 실험 결과는 '이전 버전'으로 표시 |
| C. 시뮬레이션 검증 추천 | Battle Data 유료 몬테카를로(선출) | 교체 추천 자체를 같은 상대·난수 짝지은 비교로 검증하고 신뢰구간이 0을 넘지 않으면 '결론 보류' |
| D. 전술 매치업 | Team Analyzer 6×6·선출, Battle Data 유료 선출 탐색 | 상대 세트를 사용률 분포 가설 여러 개로 보고 데미지 범위·KO·선공 조건을 함께, 상대 전략은 확률 분포로 |
| E. 전략 발견 | 미확인 | 자동 연구(MAP-Elites)와 전략 무결성 검사(시동·수혜 동반, 실제 실행률) |
| F. 개인 개선 | Porygon Labs 전적 기록, Battle Data 녹화 | 실전 기록을 모의전 예측과 비교해 선출 실수와 구조 문제를 나누고 다음 실험 가설 제안. 적은 표본으로 메타 확률을 바꾸지 않음 |

## 4. 설계에 반영한 점 (복제하지 않고 재설계)

1. 대부분의 빌더는 '사용률 기본 세트 + 정적 상성'에 머문다. Vextrum은 정적 분석을 빠른 층으로 두고, 승률은 오직 모의전에서만 말한다.
2. Team Analyzer의 교체 점수는 정적이다. Vextrum 진단(`VEXTRUM_V4_DIAGNOSTIC_REPORT.md`)에서 정적 초안 점수와 실제 승률의 상관이 0.067이었으므로,
   교체 추천 화면은 정적 순위를 '후보 찾기'에만 쓰고 결론은 모의전으로 낸다.
3. Battle Data의 선출 몬테카를로는 유료·데스크톱 전용이다. Vextrum은 같은 질문을 팀 편집 흐름 안에서 바로 실험할 수 있게 한다.
4. Porygon Labs의 전적 기록 항목(상대 아키타입·선봉·선출·메모)은 실전 기록의 최소 입력으로 적절하다. Vextrum은 여기에 모의전 예측과의 차이를 붙인다.
