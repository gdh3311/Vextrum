# Champions Meta Lab

Pokémon Champions 메타 분석 + 팀 빌더 + 조커 파인더. 더블배틀 기본, 싱글배틀 전환 지원.

```
backend/   FastAPI + 분석 엔진 (Python), SQLite 순위 스냅샷
app/       Flutter 앱 (web / windows / android) — Riverpod, GoRouter, Dio
```

## 내려받아 바로 실행 (Windows, 베타)

[Releases](https://github.com/gdh3311/Vextrum/releases)에서 `Vextrum-<버전>-beta-windows-x64.zip` 을 받아 풀고 `Vextrum.exe` 를 실행한다.
파이썬 설치가 필요 없다 (백엔드는 `backend/vextrum-backend.exe` 로 동봉, 앱이 켜고 끈다). 서명하지 않은 베타라 SmartScreen 경고가
뜨면 '추가 정보' → '실행'. 배포판 만들기: `backend/.venv/Scripts/python tools/package_release.py` → `dist/`.

## 실행 (개발)

```bash
cd backend
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
.venv/Scripts/python -m app.collector          # 데이터 수집 (처음 1회, 이후 갱신할 때)
.venv/Scripts/python -m uvicorn app.main:app --port 8000
```

`app/build/web` 이 있으면 백엔드가 웹 앱까지 같이 서빙하므로 http://localhost:8000 만 열면 된다.

```bash
cd app
flutter build web --release      # 웹 빌드 (백엔드가 서빙)
flutter run -d windows           # 또는 데스크톱 앱으로 실행
flutter run --dart-define=API_BASE=http://10.0.2.2:8000   # 안드로이드 에뮬레이터
```

## 분석 방식과 한계

- 원본에 종 단위 **사용률(%)이 없고 순위만** 있다. 메타 가중치는 `1/sqrt(순위)`, 조커 조건은 "N위 밖"으로 처리한다.
- 능력치 = Lv.50 실수치 + 능력 포인트(1포인트 = +1, 한 능력치 32 / 총 66) × 성격 보정.
- 팀 분석의 데미지 표는 근사치다 (평균 난수, 급소·랭크 변화 미반영). 상대는 "가장 흔한 세트"로 가정한다.
- 가상 배틀은 챔피언스 규칙을 따른다 (`backend/app/mechanics.py`): 마비 스피드 ×0.5·행동 불가 12.5%, 잠듦 최대 2턴,
  얼음 25% 해동·3턴째 해동, 맹독 교체 시 초기화, 급소 1/24 ×1.5, 난수 85~100%, 챔피언스에서 바뀐 기술 위력·명중·추가 효과,
  벽·설치 기술·대타·앙코르·하품·씨뿌리기·소원 등 보조기, 주요 메가 특성, 필드 시드·하양허브·멘탈허브·잠깨는열매·노말주얼·빛의가루 등 도구. 아직 없는 것: 혼란, 멸망의노래, 강제 교체, 일부 특수 특성.
- `backend/tools_validate_meta.py` 는 실제 팀원 통계로 만든 팀끼리 싸운 시뮬 승률과 사용률 순위의 상관을 잰다.
  사용률은 인기 지표라 승률과 상관이 거의 없게 나온다(현재 ±0.1). 이상치를 찾아 규칙 누락(예: 노가드, 메가스톤 연결 오류)을 고치는 용도다.
- 승률, 선봉 데이터는 원본에 없다. 상대 분석의 **예상 선봉은 추정치**다
  (동료 채용 순서 + 역할 시너지 + 내 팀 압박도, `backend/app/enemy.py`).
- 7일/14일 추세는 수집할 때마다 `backend/data/history.sqlite` 에 쌓이는 스냅샷으로 계산한다
  (지금은 지난 시즌 대비 변동만 표시).

## 주요 기능

- 메타: 랭킹(행을 누르면 채용률·동료·상성 상세), 타입 필터, 상승/하락, 메가·기술·도구·특성 채용
- 팀 빌더: 여러 팀 저장·전환·복제·이름 변경, 세트 편집, 텍스트 내보내기/가져오기(Showdown 형식, 능력 포인트는 `SPs:` 줄)
- 팀 자동 구성 (`backend/app/auto_team.py`): 스피드·물리·특수·내구·균형 중심, 날씨, 세부 전술, 조커(제외·허용·1마리 필수),
  메가진화(자동·1마리 필수·없음), 타입 조합(불·물·풀, 드래곤·강철·페어리, 약점 최소화)을 고른다. 초안 점수는 메타 상성·역할·약점과
  함께 랭커 파티에서 기대보다 자주 함께 쓰인 쌍을 가산하고, 사용률 가중치는 낮췄다. 메가스톤은 1개를 넘으면 크게 감점한다.
  후보는 같은 상대군에서 거르고 최종 후보를 다시 검증하며, 랭커 파티 상대 전적과 그 기준(메타·랭커 반반)의 순위도 낸다.
- 팀 개성: 메타 중심·균형(기본)·독창적. 균형은 랭커 파티와 최대 3마리, 독창적은 2마리까지만 겹치게 하는 '하드 제한'을 두고
  그 안에서 승률만 최적화한다 (꼭 넣을 포켓몬 때문에 더 겹치면 그만큼 허용). 사용률 가중치를 낮추고, 전략마다 사용률 최상위 몇 종을
  뺀 '에이스'에서 출발한 초안을 깊이에 따라 4~9개씩 더 만든다.
- 후보 경주 (`_race`): 후보 36/56/90팀(빠르게/표준/정밀)을 모두 짧게 싸우게 한 뒤, 누적 성적이 좋은 팀만 다음 단계에서 더 싸운다
  (예: 표준 12판 → 상위 22팀 24판 → 상위 10팀 32판). 단계마다 5마리 이상 같은 팀은 성적이 좋은 하나만 남긴다.
- `tools_bench_builder.py`: 12가지 조건으로 팀을 만들고, 보여 준 팀을 만들 때 쓰지 않은 새 상대군에서 200판씩 다시 싸워
  선별 운이 빠진 승률을 잰다. 표준 깊이·세트 최적화 끔 기준:
  메타 중심 33종·랭커 파티와 4마리 이상 겹침 34/36팀·평균 72.8%·조건별 최고 팀 75.7%,
  균형 47종·0/36팀·67.7%·71.1% (개선 전 균형: 42종·1/36팀·64.2%).
- 멤버 교체 실험 (`backend/app/roster_search.py`): 1차 모의전에서 진 상대와 전략을 보고 그 상대를 잘 받는 포켓몬으로 1~2마리를
  바꾼 조합을 만들어, 같은 상대군과 새 상대군에서 모두 나아질 때만 교체한다.
- 조건 충돌: 싱글에서 쓸 수 없는 더블 전용 전술은 빼고 만들며, 메가·조커·고정 조건은 모든 후보 단계에서 같은 규칙으로 검사한다.
- 가상 배틀 상대(CPU)는 실전 채용 도구를 지니고, 파티의 92%에 메가진화 포켓몬을 넣으며 선출할 때도 메가 포켓몬을 우선 데려간다.
- V2 엔진 (`docs/V2_AUDIT.md`): 전략 우선 생성(하이브리드 블루프린트 `backend/app/strategy.py`), 다중 라벨 전략 태그와
  주/보조 승리 조건, 패배 원인(상대가 전개한 트릭룸·순풍·날씨 등), 다른 CPU 정책 견고성, 파레토·다양성 선별(공격형·안정형·변칙형).
  골든 메커닉 테스트 `backend/tests/test_golden.py`. 시즌·레귤레이션 출처는 `backend/app/regulation.py`.
- 랭크 리그 검증 (v3): 최종 후보를 몬스터볼(기본 점검)·하이퍼볼(탐색)·마스터볼(검증)·챔피언(보류)·스트레스(약한 아키타입 집중)
  리그에서 따로 싸우게 해 95% 범위와 함께 보여 준다. CPU는 상대의 공개 정보만 본다(`Battle._seen`). 랭크 벤치마크 `tools_bench_tiers.py`.
- v4 선출 공동 최적화 (`backend/app/policy.py`): 미리보기로 추정한 상대 전략마다 선봉·후발을 같은 판에서 비교하고 새 상대군에서
  다시 확인해 채택. CPU 플레이 스타일(균형·공격·수비·전개·피벗·카운터, `tools_bench_styles.py`). 모든 변경 채택은 같은 판 차이의 신뢰 하한으로.
- v6 (기본 엔진, `docs/VEXTRUM_V4_DIAGNOSTIC_REPORT.md`): v4 + 평가 편향 제거. 선별 CPU 스타일 혼합, 최종 선택은 탐색에 쓰지 않은
  시드의 마스터볼 혼합 스타일, 보류 효과가 없던 선출 최적화 제거. 독립 보류에서 v4 대비 팀 평균 챔피언 +3.6%p·마스터볼 +5.7%p,
  빌드 시간 절반. 진단 실험 `backend/tools_diag_v4.py`, 시뮬레이터 감사 `backend/tools_audit_sim.py`.
- v5: 탐색 중간에도 간이 선출 최적화(`policy.quick`)를 돌려 그 계획을 깔고 멤버 교체를 비교한다. 미리보기는
  랭커 채용률로 전략 확률(`battle_lab.preview_strategy`)을 내고, 애매하면 두 전략 혼합 열쇠(`mix:a|b`)로 따로 검증한다
  (`tools_bench_preview.py`). 자동 연구는 '팀 + 선출 계획'을 한 개체로 저장하고, 팀 개성 설정마다 다른 겹침 구간에서 시드를 고른다.
  독창성 다섯 갈래와 반사실 요약(`backend/app/novelty.py`), 시즌 신뢰도 가중치와 데이터 경고(`regulation.data_warnings`),
  버전 짝지은 비교(`tools_bench_versions.py`).
- 자동 연구 (`backend/app/research.py`, 앱의 '자동 연구' 화면): 서버가 켜져 있는 동안 뒤에서 계속 돈다. 세대마다 새 초안(무작위
  전략·에이스·개성), 잘하는 팀의 변이(멤버 1마리 교체·세트 변경), 두 팀의 교배, 유망한 팀의 재검증을 만들어 매번 새 난수의
  메타 상대군과 싸운다. 팀별 누적 성적과 함께 쓴 포켓몬 쌍의 승률(시너지)을 `backend/data/research.sqlite` 에 쌓고,
  전략 성격 × 랭커 파티와 겹치는 정도(틈새, 최대 27칸)마다 하한 신뢰구간이 높은 팀을 기록한다(MAP-Elites 방식).
  교체 후보는 배운 시너지로 고르고, 팀 자동 구성은 조건에 맞는 기록 상위 팀을 출발점에 넣는다. 사용자의 팀 구성 작업 중에는 쉰다.
  세기: 낮게(기본)·보통·최대. 데이터가 갱신되면 새 버전으로 다시 쌓는다.
- 세트 최적화 (`backend/app/set_tuner.py`): 최종 후보의 포켓몬마다 도구(실제 채용 + 역할 규칙: 공격수 생명의구슬·달인의띠·타입 강화·
  구애스카프, 연약한 포켓몬 기합의띠, 내구형 자뭉열매·울퉁불퉁멧, 메타가 노리는 약점 반감 열매), 합법 특성, 팀이 못 받는 상대를
  더 무겁게 본 기술 조합, 최속·내구·트릭룸 능력 포인트를 만든다. 짧은 시뮬레이션으로 거른 뒤 새 상대군에서 다시 확인하고,
  합친 결과가 세 번째 상대군에서도 1%p 이상 나을 때만 반영한다. 사용률 세트는 대개 강해서 바뀌지 않는 경우가 많다.
  배틀 엔진이 아직 단점을 계산하지 않는 기술(역린 등)과 도구(탈출버튼·레드카드 등)는 새로 넣거나 바꾸지 않는다.
- 시뮬레이션은 `backend/app/parallel.py` 가 CPU 코어에 팀 단위로 나눠 돌린다 (같은 상대·같은 난수라 결과는 순차 실행과 같다).
  `SIM_PARALLEL=0` 이면 순차 실행.
- 전략 가이드: 팀 운영법, 기본 선출, 주력, 조합 활용/주의점, 메타 전략별 대비, 위험 상대 대응법 (`backend/app/guide.py`)
- 약점·상성 분석: 규칙 위반(중복 포켓몬·도구), 타입 상성표, 역할 구성, 메타 상성, 교체 추천
- 실전 상대 분석: 상대 6마리 빠른 입력과 더블 전략 연습 조합, 상대의 선봉·후발 추정, 내 선봉 2마리·후발 2마리 추천. 내 선출을 고정하고 실제 상대 선봉을 확인하면 첫 턴 행동과 후반에 남길 대응을 갱신한다.
- 실전 기록: 확인한 상대 선봉·후발, 승패와 메모를 기기에 저장한다. 동일 구성 상대 전적과 관측 선봉을 조회할 수 있다.
- 포켓몬 연구실(상세 화면): 세트를 골라/편집해 메타 상위권과의 1:1 우열표, 기술별 데미지 범위·확정수 대결 창,
  추천 파트너와 이유, 운용법, 채용 통계 (`backend/app/lab.py`)
- 조커 파인더
- CPU 난이도: 몬스터볼~챔피언 5단계. 챔피언은 상대 행동을 예측해 2턴 앞까지 진행해 보고 최악의 경우까지 따지는 탐색형 CPU
  (`backend/app/battle_ai.py`). 강도는 `backend/tools_bench_mirror.py`(같은 4마리끼리 붙이는 미러 매치)로 잰다:
  표준 정책 상대 승률 하이퍼볼 51.5% · 마스터볼 72.5% · 챔피언 약 76~78% (200판, 표준 정책도 순풍을 쓰게 된 뒤 기준).
  순풍·트릭룸은 실제로 선공이 뒤집히는 (내 포켓몬, 상대) 쌍의 수로 가치를 매긴다(`Battle._speed_control_value`).
  엘풍 선봉의 첫 2턴 안 순풍 사용률: 하이퍼볼 10% → 80%, 챔피언 42% → 60%대.
- 시뮬레이션 상세: 승률 95% 신뢰 구간, 포켓몬별 선출·생존·피해·KO, 선봉 조합별 승률, 위협적인 상대, 경기 길이 분포.
  팀 자동 구성은 평가 깊이(빠르게/표준/정밀)와 최종 검증 CPU를 고를 수 있고 후보 비교표·팀 분석을 보여 준다.
- 스피드 티어: 메타 상위권의 주력 세트 스피드(최속·준속·무보정·최저속, 구애스카프 채용률 포함)와 내 팀을 한 줄로 비교, 순풍·트릭룸 보기
- 팀 가져오기: Showdown 텍스트와 pokepast.es 링크
- 시즌별 메타: 최신 시즌과 과거 시즌의 랭킹을 전환한다. 과거 포켓몬 상세는 해당 시즌의 마지막 가용 스냅샷을 받아 로컬에 캐시한다.
- 파티 탐색: 공개 랭커 파티(시즌 M6·M7 더블 상위권 29팀), 전략별 추천, 추천 파티 연구소. 세트가 공개된 파티와 추천 파티는 새 팀으로 저장할 수 있다.
- 추천 파티 연구소 (`backend/app/recommend.py`): 랭커 파티에서 상위권 가중치로 센 동시 채용 코어(2·3마리)와 전략, 조커 후보를
  시작점으로 6마리를 채운다. 모든 후보를 같은 메타 상대군(전략별 생성 파티)과 랭커 파티 전체(공개된 종 구성 + 가장 흔한 세트)를
  상대로 같은 난수에서 싸우게 해 거르고, 최종 후보를 더 많은 판과 고른 CPU로 다시 검증한다. 조커(사용률 40위 밖)는 제외·허용·1마리 필수,
  평가 깊이(빠르게 약 1,500판 · 표준 · 정밀), 메타/랭커 비중을 고른다. 랭커 파티별 전적을 유리(60%↑)·호각·불리(40%↓)로 보여 주고,
  허용일 때는 조커 포함 최고 팀과 미포함 최고 팀의 점수 차를 비교한다.
- 가상 배틀: 최신 메타를 바탕으로 전략의 핵심 두 역할과 타입 보완, 동료 채용을 고려해 상대 6마리를 매판 생성한다. 연습에서 상대의 구성과 세트를 보고 선봉·후발을 직접 고른다. 최대 200판의 반복 배틀은 전략별 판수를 고르게 배정하고 양쪽이 상대 로스터를 보고 자동 선출한다. 전략별 승패, 선봉·후발 조합, 상대 선출과 KO를 확인하고 표본 경기의 상대를 다시 불러 연습할 수 있다. 결과를 기기에 저장하고 JSON으로 복사할 수 있다. 승률은 앱의 근사 엔진과 CPU 정책 기준이다.
- 직접 플레이: 기술과 대상을 텍스트 명령으로 고르고, 기절한 자리에 내보낼 포켓몬을 지정한다. 상대 후발은 필드에 등장할 때 공개한다. 몬스터볼부터 챔피언까지 다섯 CPU 난이도를 직접 플레이와 자동 시뮬레이션에서 선택할 수 있다.

- 설정: 언어(한국어/English/日本語), 이름 표시, 테마(시스템/어둡게/밝게), 글자 크기, 애니메이션 줄이기, 경기장 배경,
  기본 배틀 형식, 서버 주소·연결 확인, 데이터 갱신, 로컬 데이터 초기화
- 다국어: 화면 문구는 `app/l10n/translations.tsv`(한국어 원문 · 영어 · 일본어)에서 `python tools/gen_l10n.py` 로
  `app/lib/l10n_data.dart` 를 만들고, 앱이 그릴 때 번역한다(`app/lib/i18n.dart`). 포켓몬·기술·도구·특성·성격 이름은
  요청 헤더 `X-Lang` 에 맞춰 서버가 바꿔 보낸다(`backend/app/names.py`). 서버가 만드는 설명 문장은 아직 한국어.
