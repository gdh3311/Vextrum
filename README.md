# Champions Meta Lab

Pokémon Champions 메타 분석 + 팀 빌더 + 조커 파인더. 더블배틀 기본, 싱글배틀 전환 지원.

```
backend/   FastAPI + 분석 엔진 (Python), SQLite 순위 스냅샷
app/       Flutter 앱 (web / windows / android) — Riverpod, GoRouter, Dio
```

## 실행

```bash
cd backend
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
.venv/Scripts/python -m app.collector          # 데이터 수집 (처음 1회, 이후 갱신할 때)
.venv/Scripts/python -m uvicorn app.main:app --port 8000
```

`app/build/web` 이 있으면 백엔드가 웹 앱까지 같이 서빙하므로 http://localhost:8000 만 열면 된다.

```bash
cd app
flutter build web --release      # 웹 빌드 (백엔드가 서빙)
flutter run -d windows           # 또는 데스크톱 앱으로 실행
flutter run --dart-define=API_BASE=http://10.0.2.2:8000   # 안드로이드 에뮬레이터
```

## 데이터

- 배틀 데이터: [Pokémon Champions Battle Data](https://championsbattledata.com) API — 순위, 기술/도구/특성/성격/능력 포인트 채용률, 동료.
  **Battle data provided by Pokémon Champions Battle Data.** (공개 시 출처 표기 필수, 원본 데이터 재배포 금지)
- 기술 정보(타입/위력/명중/우선도): Pokémon Showdown `moves.json`
- 한글 이름: PokeAPI CSV
- 아이콘: 원본 사이트 에셋을 백엔드가 받아 `backend/data/cache/img` 에 캐시

## 분석 방식과 한계

- 원본에 종 단위 **사용률(%)이 없고 순위만** 있다. 메타 가중치는 `1/sqrt(순위)`, 조커 조건은 "N위 밖"으로 처리한다.
- 능력치 = Lv.50 실수치 + 능력 포인트(1포인트 = +1, 한 능력치 32 / 총 66) × 성격 보정.
- 팀 분석의 데미지 표는 근사치다 (평균 난수, 급소·랭크 변화 미반영). 상대는 "가장 흔한 세트"로 가정한다.
- 가상 배틀은 챔피언스 규칙을 따른다 (`backend/app/mechanics.py`): 마비 스피드 ×0.5·행동 불가 12.5%, 잠듦 최대 2턴,
  얼음 25% 해동·3턴째 해동, 맹독 교체 시 초기화, 급소 1/24 ×1.5, 난수 85~100%, 챔피언스에서 바뀐 기술 위력·명중·추가 효과,
  벽·설치 기술·대타·앙코르·하품·씨뿌리기·소원 등 보조기, 주요 메가 특성. 아직 없는 것: 혼란, 멸망의노래, 강제 교체, 일부 특수 특성.
- `backend/tools_validate_meta.py` 는 실제 팀원 통계로 만든 팀끼리 싸운 시뮬 승률과 사용률 순위의 상관을 잰다.
  사용률은 인기 지표라 승률과 상관이 거의 없게 나온다(현재 ±0.1). 이상치를 찾아 규칙 누락(예: 노가드, 메가스톤 연결 오류)을 고치는 용도다.
- 승률, 선봉 데이터는 원본에 없다. 상대 분석의 **예상 선봉은 추정치**다
  (동료 채용 순서 + 역할 시너지 + 내 팀 압박도, `backend/app/enemy.py`).
- 7일/14일 추세는 수집할 때마다 `backend/data/history.sqlite` 에 쌓이는 스냅샷으로 계산한다
  (지금은 지난 시즌 대비 변동만 표시).

## 주요 기능

- 메타: 랭킹(행을 누르면 채용률·동료·상성 상세), 타입 필터, 상승/하락, 메가·기술·도구·특성 채용
- 팀 빌더: 여러 팀 저장·전환·복제·이름 변경, 세트 편집, 텍스트 내보내기/가져오기(Showdown 형식, 능력 포인트는 `SPs:` 줄)
- 팀 자동 구성: 스피드·물리·특수·내구·균형 중심과 날씨, 세부 전술을 고른다. 역할별 목표 인원과 날씨를 만드는 포켓몬 및 활용할 공격수를 구성에 반영하며, 지정·고정·제외 포켓몬을 반영한다. 후보들은 같은 상대군에서 21판씩 평가하고, 최종 후보는 새 공통 상대군에서 56판씩 검증한다. 종합 승률 또는 전략별 최저 승률을 비교해 팀을 저장하고 배틀할 수 있다.
- 전략 가이드: 팀 운영법, 기본 선출, 주력, 조합 활용/주의점, 메타 전략별 대비, 위험 상대 대응법 (`backend/app/guide.py`)
- 약점·상성 분석: 규칙 위반(중복 포켓몬·도구), 타입 상성표, 역할 구성, 메타 상성, 교체 추천
- 실전 상대 분석: 상대 6마리 빠른 입력과 더블 전략 연습 조합, 상대의 선봉·후발 추정, 내 선봉 2마리·후발 2마리 추천. 내 선출을 고정하고 실제 상대 선봉을 확인하면 첫 턴 행동과 후반에 남길 대응을 갱신한다.
- 실전 기록: 확인한 상대 선봉·후발, 승패와 메모를 기기에 저장한다. 동일 구성 상대 전적과 관측 선봉을 조회할 수 있다.
- 포켓몬 연구실(상세 화면): 세트를 골라/편집해 메타 상위권과의 1:1 우열표, 기술별 데미지 범위·확정수 대결 창,
  추천 파트너와 이유, 운용법, 채용 통계 (`backend/app/lab.py`)
- 조커 파인더
- CPU 난이도: 몬스터볼~챔피언 5단계. 챔피언은 상대 행동을 예측해 2턴 앞까지 진행해 보고 최악의 경우까지 따지는 탐색형 CPU
  (`backend/app/battle_ai.py`). 강도는 `backend/tools_bench_mirror.py`(같은 4마리끼리 붙이는 미러 매치)로 잰다:
  표준 정책 상대 승률 하이퍼볼 51.5% · 마스터볼 72.5% · 이전 챔피언 77% · 현재 챔피언 81.5% (200판).
- 시뮬레이션 상세: 승률 95% 신뢰 구간, 포켓몬별 선출·생존·피해·KO, 선봉 조합별 승률, 위협적인 상대, 경기 길이 분포.
  팀 자동 구성은 평가 깊이(빠르게/표준/정밀)와 최종 검증 CPU를 고를 수 있고 후보 비교표·팀 분석을 보여 준다.
- 스피드 티어: 메타 상위권의 주력 세트 스피드(최속·준속·무보정·최저속, 구애스카프 채용률 포함)와 내 팀을 한 줄로 비교, 순풍·트릭룸 보기
- 팀 가져오기: Showdown 텍스트와 pokepast.es 링크
- 시즌별 메타: 최신 시즌과 과거 시즌의 랭킹을 전환한다. 과거 포켓몬 상세는 해당 시즌의 마지막 가용 스냅샷을 받아 로컬에 캐시한다.
- 파티 탐색: 공개 랭커 파티, 전략별 추천, 공통 상대군에서 검증한 시뮬레이션 추천을 볼 수 있다. 세트가 공개된 파티와 추천 파티는 새 팀으로 저장할 수 있다.
- 가상 배틀: 최신 메타를 바탕으로 전략의 핵심 두 역할과 타입 보완, 동료 채용을 고려해 상대 6마리를 매판 생성한다. 연습에서 상대의 구성과 세트를 보고 선봉·후발을 직접 고른다. 최대 200판의 반복 배틀은 전략별 판수를 고르게 배정하고 양쪽이 상대 로스터를 보고 자동 선출한다. 전략별 승패, 선봉·후발 조합, 상대 선출과 KO를 확인하고 표본 경기의 상대를 다시 불러 연습할 수 있다. 결과를 기기에 저장하고 JSON으로 복사할 수 있다. 승률은 앱의 근사 엔진과 CPU 정책 기준이다.
- 직접 플레이: 기술과 대상을 텍스트 명령으로 고르고, 기절한 자리에 내보낼 포켓몬을 지정한다. 상대 후발은 필드에 등장할 때 공개한다. 몬스터볼부터 챔피언까지 다섯 CPU 난이도를 직접 플레이와 자동 시뮬레이션에서 선택할 수 있다.

- 설정: 언어(한국어/English/日本語), 이름 표시, 테마(시스템/어둡게/밝게), 글자 크기, 애니메이션 줄이기, 경기장 배경,
  기본 배틀 형식, 서버 주소·연결 확인, 데이터 갱신, 로컬 데이터 초기화
- 다국어: 화면 문구는 `app/l10n/translations.tsv`(한국어 원문 · 영어 · 일본어)에서 `python tools/gen_l10n.py` 로
  `app/lib/l10n_data.dart` 를 만들고, 앱이 그릴 때 번역한다(`app/lib/i18n.dart`). 포켓몬·기술·도구·특성·성격 이름은
  요청 헤더 `X-Lang` 에 맞춰 서버가 바꿔 보낸다(`backend/app/names.py`). 서버가 만드는 설명 문장은 아직 한국어.
